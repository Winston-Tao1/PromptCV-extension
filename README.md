## 🎯 产品简介

**Prompt** 是一款专为 AI 工作者设计的 Chrome 浏览器扩展，提供专业的提示词管理解决方案。

### 核心价值

- 📚 **集中管理** - 统一管理所有 AI 提示词
- ⚡ **快速调用** - 一键复制，提高工作效率
- 💾 **本地缓存** - 支持富文本、文件、图片存储
- 🎯 **多模型配置** - 轻松管理多个 AI 模型
- 🔄 **云端同步** - 提示词跨设备自动同步

## 🚀 快速开始

### 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/Winston-Tao1/Prompt-extension.git
   cd Prompt-extension
   ```

2. **加载到 Chrome**
   - 访问 `chrome://extensions/`
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目文件夹

3. **开始使用** 🎉

## ✨ 核心功能

### 📋 提示词管理

- ⭐ **收藏系统** - 星标重要提示词，快速访问
- 🏷️ **标签分类** - 12 种预设标签，最多选择 3 个
- ✏️ **在线编辑** - 点击卡片即可编辑，自动保存
- 🗑️ **安全删除** - 确认弹窗防止误删
- 📊 **自动排序** - 按时间倒序显示最近 20 条

**支持标签：** 代码编程、内容创作、学习研究、工作办公、生活娱乐、专业领域、DeepSeek、ChatGPT、Grok、Gemini、豆包、Claude

### 🤖 AI 增强功能

#### 提示词润色
- 一键优化提示词表达
- 使用配置的 AI 模型
- 实时显示润色进度

#### 提示词反推
- 从 AI 输出反推原始提示词
- 智能分析文本特征
- 自动保存反推结果

### 💾 本地缓存系统

#### 富文本编辑器
- **格式化工具**：加粗、字体、字号、颜色
- **颜色选择器**：8 种预设 + 色谱画布
- **自动保存**：1 秒防抖，防止数据丢失

#### 文件管理（支持所有格式）
```
文档：txt, doc, docx, pdf, md
表格：xls, xlsx, csv
演示：ppt, pptx
图片：jpg, png, gif, svg
压缩：zip, rar, 7z
代码：js, py, java, html, css, json
音视频：mp3, wav, mp4, avi, mkv
其他：支持所有格式！
```

#### 图片处理
- **粘贴支持**：Ctrl+V 直接粘贴截图
- **缩略图显示**：70% 缩放（最大 140px）
- **操作按钮**：下载、删除（悬停显示）

### ⚙️ AI 模型配置

- **多模型支持**：最多 5 个配置
- **一键切换**：绿色开关快速激活
- **安全存储**：API Key 本地加密存储
- **配置管理**：添加、启动、关闭、删除

**推荐平台：** [胜算云](https://www.shengsuanyun.com/?from=CH_6QLLV1BO)

### 🎨 个性化定制

- **自定义 Logo**：支持所有图片格式，无大小限制
- **可编辑标题**：最多 20 个字符
- **Material Design**：Google 风格设计

## 📖 使用指南

### 1️⃣ 添加提示词

1. 点击"**添加**"标签
2. 选择 1-3 个标签
3. 输入提示词内容
4. 点击"保存"（自动复制到剪贴板）

### 2️⃣ 管理提示词

- **收藏**：点击 ⭐ 图标
- **复制**：点击"📋 复制"按钮
- **编辑**：点击卡片任意位置
- **删除**：点击右上角 ⋮ 菜单

### 3️⃣ 配置 AI 模型

1. 点击右上角"⚙️ 设置"
2. 填写 API 信息
3. 点击"保存配置"
4. 点击灰色开关启动模型

### 4️⃣ 使用缓存功能

1. 点击"**缓存**"标签
2. 使用工具栏格式化文本
3. 上传文件或粘贴图片
4. 内容自动保存到本地

## 🔒 数据安全

### 存储策略

| 数据类型 | 存储位置 | 同步 | 说明 |
|---------|---------|------|------|
| 提示词 | Chrome Sync | ✅ | 跨设备同步 |
| 缓存内容 | Chrome Local | ❌ | 本地大容量存储 |
| AI 配置 | Chrome Local | ❌ | 隐私保护 |
| 自定义设置 | Chrome Local | ❌ | 个性化配置 |

### 隐私承诺

- ✅ **零云端上传** - 敏感数据仅存本地
- ✅ **端到端加密** - 使用 Chrome 安全存储
- ✅ **用户掌控** - 数据完全由用户控制
- ✅ **无追踪** - 不收集任何使用数据

## 🐛 常见问题

**Q: 数据会丢失吗？**  
A: 提示词云同步不会丢失；缓存本地存储，清除浏览器数据才会丢失。

**Q: 支持哪些文件格式？**  
A: 支持所有格式，无限制！

**Q: 如何获取 API Key？**  
A: 推荐访问 [胜算云平台](https://www.shengsuanyun.com/?from=CH_6QLLV1BO) 注册获取。

**Q: 头像上传有大小限制吗？**  
A: 没有限制，支持任意大小的图片文件。
